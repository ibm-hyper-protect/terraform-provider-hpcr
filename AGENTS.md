# AGENTS.md

This file provides guidance to agents when working with code in this repository.

## Project

Go-based Terraform provider for IBM Hyper Protect Container Runtime (HPCR). Uses **Terraform Plugin Framework** (not the older SDK v2 — depguard bans all `terraform-plugin-sdk/v2` imports).

Module: `github.com/ibm-hyper-protect/terraform-provider-hpcr`

## Commands

```bash
make fmt          # gofmt -s -w -e .
make lint         # golangci-lint run
make build        # go build -v ./...
make install      # build + go install (puts binary in $GOPATH/bin)
make test         # go test -v -cover -timeout=120s -parallel=10 ./...
make testacc      # TF_ACC=1 go test -v -cover -timeout 120m ./...
make generate     # runs tools/go generate (docs + copyright headers)
make tidy         # go mod tidy
```

**Run a single test:**
```bash
go test -v -run TestFunctionName ./path/to/package/...
# Example:
go test -v -run TestTgzResource_Schema ./internal/provider/resources/...
```

**Unit tests require `openssl` in PATH** — `common.GeneratePrivateKey()` shells out to `openssl genrsa 4096`. Override via `OPENSSL_BIN` env var.

**Acceptance tests** require `TF_ACC=1` and real IBM Cloud credentials (`IBM_CLOUD_API_KEY`). They call live IBM Cloud APIs and take ~90 minutes. In CI, add the `run-acceptance-tests` label to a PR to trigger them.

## Architecture

```
main.go                            ← provider entrypoint, version/commit set by goreleaser ldflags
common/common.go                   ← shared utilities: GenerateID, GeneratePrivateKey, ReadFileData, RefineContract, FilterChecksum
internal/provider/provider.go     ← registers all resources and datasources
internal/provider/resources/      ← 8 resources (tgz, tgz_encrypted, text, text_encrypted, json, json_encrypted, contract_encrypted, contract_encrypted_contract_expiry)
internal/provider/datasources/    ← 4 datasources (image, attestation, encryption_certs, encryption_cert)
tools/                            ← go:generate wiring for tfplugindocs + copywrite headers
```

All cryptographic/HPCR operations delegate to `github.com/ibm-hyper-protect/contract-go/v2` — never implement them directly.

## Code Patterns

**Resource model struct tags use `tfsdk:"..."` not `json:"..."`:**
```go
type TgzResourceModel struct {
    ID       types.String `tfsdk:"id"`
    Rendered types.String `tfsdk:"rendered"`
}
```

**All resources and datasources are stateless empty structs** — no fields in the struct itself. State lives entirely in the model.

**`Delete` is a no-op on all resources** — these resources generate computed data (encrypted contracts, archives), not remote infrastructure.

**`Read` just reflects state back** — no remote API calls; re-reads from prior state only.

**ID generation pattern** — every Create uses `common.GenerateID()` (UUID via `go-uuid`). ID uses `stringplanmodifier.UseStateForUnknown()` to preserve across updates.

**Optional attribute check pattern:**
```go
if !data.Cert.IsNull() && !data.Cert.IsUnknown() {
    cert = data.Cert.ValueString()
}
```

**`RefineContract`** in `common/` is a non-obvious YAML transform: it re-serializes `env` and `workload` keys as YAML block literals (literal style) inside the outer YAML. Call this before passing to `contract.HpcrContractSignedEncrypted`.

**`FilterChecksum`** parses SHA-256 checksum files (64 hex chars + filename) into a `map[string]string`.

**Schema requires both `Description` and `MarkdownDescription`** on every schema and attribute — tests assert both fields are non-empty.

**Interface compliance assertions are required** at package level:
```go
var _ resource.Resource = &TgzResource{}
var _ datasource.DataSource = &ImageDataSource{}
```

## Code Style

- Apache-2.0 license header on every `.go` file (copyright year 2026) — enforced by `copywrite` in `make generate`
- `gofmt -s` formatting enforced by `golangci-lint` with the `gofmt` formatter
- `godot` linter: exported comments must end with a period
- Import grouping: stdlib → third-party framework imports → internal `contract-go/v2` imports → local `common` package
- **Do not use `terraform-plugin-sdk/v2`** — use only `terraform-plugin-framework`

## Releases & Commits

- Commits must follow **Conventional Commits**: `feat|fix|docs|perf|revert|chore|refactor|test|build|ci`
- **Do not manually edit `CHANGELOG.md`** — generated by `semantic-release` on merge to `main`
- Releases: `semantic-release` → git tag → GoReleaser builds + signs with GPG → Terraform Registry
- `version` and `commit` variables in `main.go` are set by goreleaser ldflags at release time

## Documentation Generation

```bash
make generate   # runs from tools/ submodule with its own go.mod
```

Generates `docs/` from resource schemas + `examples/` using `tfplugindocs`. Example configs live in `examples/resources/<resource_name>/` and `examples/data-sources/<datasource_name>/`.
